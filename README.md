## 🌟 Project Overview

**The Glimmerveil Courts** is a clean, linear Fae-themed trading card collection and burning economy built on the WAX blockchain. Designed with player transparency and long-term asset value in mind, the collection features:

* **0% Custom Token Complexity:** Pure NFT-to-NFT card collection and blending.
* **Deflationary Mechanics:** Base cards are permanently burned during blending to control circulating supply.
* **Fair Royalty Structure:** A 4% secondary market creator fee balances project growth with trading liquidity.
